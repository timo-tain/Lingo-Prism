> **Lingo Prism — нативный переводчик экрана для macOS: он распознаёт выбранную область с помощью локального OCR и накладывает перевод на исходное место текста.**

Приложение предназначено для чтения интерфейсов, изображений, субтитров и документов на иностранных языках без перехода из текущего приложения.

## Возможности

- **Перевод поверх экрана**: перевод перерисовывается на исходном месте, а окружающая разметка сохраняется.
- **Плавный выбор области**: запуск из строки меню или глобальным сочетанием клавиш; область остаётся видимой во время OCR и перевода.
- **Локальный Vision OCR**: распознавание выполняется на Mac; поддерживаются автоопределение, традиционный и упрощённый китайский, английский, японский, корейский, испанский, французский, немецкий и русский языки.
- **Несколько источников перевода**: по умолчанию Google, а также Bing, Yandex, DeepL, перевод macOS, Ollama и совместимые с OpenAI локальные endpoint-ы.
- **Пресеты локальных моделей**: Ollama, LM Studio, LocalAI, vLLM, llama.cpp, Jan и пользовательские OpenAI-совместимые серверы.
- **Выделяемый результат**: текст перевода можно выделить и скопировать, переключиться на оригинал, выбрать область заново или закрыть результат.
- **Только строка меню**: приложение не отображается в Dock; можно настроить сочетание клавиш, запуск при входе и показ настроек при запуске.
- **Локализованный интерфейс**: английский, традиционный и упрощённый китайский, японский, корейский, испанский, французский, немецкий и русский языки.

## Использование

1. Откройте **Lingo Prism** из строки меню.
2. Выберите «Начать перевод экрана» или нажмите настроенное глобальное сочетание клавиш.
3. Выделите текст перетаскиванием; для отмены нажмите правую кнопку мыши или `Esc`.
4. После завершения OCR и перевода результат появится поверх исходного экрана.

В настройках можно выбрать плавающее окно, языки, движок перевода, сочетание клавиш и вид рамки.

## Конфиденциальность и поток данных

- Снимки экрана используются только для локального Vision OCR; **снимки не загружаются в сервисы перевода**.
- В выбранный движок отправляется только текст, распознанный OCR. Lingo Prism не переключает провайдера без уведомления.
- Ollama и локальные endpoint-ы позволяют хранить данные на Mac или в частной сети. Перевод macOS работает согласно настройкам macOS и Apple.
- У публичных endpoint-ов могут быть ограничения и изменения. Перед использованием в production ознакомьтесь с условиями и политикой конфиденциальности провайдера.

## Требования и разрешения

- macOS 14 или новее
- Xcode 16+ для сборки из исходников
- Разрешение **Запись экрана** для захвата выбранной области и OCR
- Разрешение **Универсальный доступ** для глобального сочетания клавиш при активном другом приложении

macOS управляет доступными языками перевода и моделями Vision OCR. Их состояние отображается в настройках Lingo Prism, откуда можно перейти в системные настройки для загрузки.

## Сборка из исходников

```bash
git clone https://github.com/<your-account>/lingo-prism.git
cd lingo-prism
swift test
./Scripts/make-app.sh
open './dist/Lingo Prism.app'
```

`make-app.sh` создаёт локально подписанное ad-hoc приложение для разработки. Для распространения используйте собственный Bundle ID, подпись Developer ID или App Store и notarization.

## Движки перевода

| Тип | Варианты |
| --- | --- |
| Публичные веб-сервисы | Google, Bing, Yandex, DeepL |
| Системный сервис | Перевод macOS |
| Локальные / self-hosted модели | Ollama, LM Studio, LocalAI, vLLM, llama.cpp, Jan и пользовательские OpenAI-совместимые endpoint-ы |

Google используется по умолчанию; вводить API-ключ или адрес сервиса в приложении не требуется. Подробности приведены в [описании движков перевода](docs/translation-engines.md).
